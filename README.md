# ipfix-export-flow-accounting-validator
验证 IPFIX 模板、采样和流计费一致性

## 功能

`ipfix_validator.py` 实现流计费校验器（兼容 Python 3.8.2）：

- **模板生命周期**：按模板 ID 维护定义历史，重定义自动撤销旧版本；
  记录版本必须与导出时刻的活动模板版本匹配，否则计入模板问题。
- **采样还原**：按记录采样率重建真实用量；记录已被预放大（pre_scaled）
  或记录与模板采样率一致时只放大一次，避免重复放大。
- **长流合并**：按五元组对流分段排序合并，乱序导出可正确还原；
  完全重复导出与时间重叠的分段只计费一次，并计入重复计费报告。
- **输出报告**：流量差异（接口计数器 − 重建总量）、模板问题、
  重复计费、无法归因记录（无活动模板或模板已撤销）。

## 运行测试

```
python -m unittest
```

测试覆盖模板重定义、采样变化、长流分片与乱序导出。

## 数据说明

所有测试使用的模板与 Data Record 均为本地构造的合成样本，
不包含任何真实网络流量数据。
